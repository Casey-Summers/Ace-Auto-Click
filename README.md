# Ace Auto Clicker (Accessibility / UI Testing Macro Tool)

## Install
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

## Run
python main.py

## Hotkey
F8 toggles start/stop globally (even when the window isn't focused).

## Safety
- Move your mouse to a screen corner to trigger PyAutoGUI failsafe (raises an exception and stops).
- This tool is intended for personal productivity, accessibility, and testing your own apps.
